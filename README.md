## 📖 Overview

MenuCard is a full-stack food ordering and menu management application designed to help restaurants manage their menu and orders digitally. It provides a modern user interface with a scalable backend architecture.

---

## ✨ Features

- 🍔 Digital menu display
- 🛒 Order management system
- 📜 Order history tracking
- ⚡ Fast and responsive UI
- 🔐 API-based backend architecture
- 📦 Scalable project structure

## 🚀 Getting Started

### ✅ Prerequisites

Make sure you have:

- Node.js installed
- npm installed
- MongoDB installed or MongoDB Atlas account
- Git installed

---

### 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/Bhavesh-Karki/MenuCard.git
```
2. Go to folder
```bash
cd MenuCard
```
3. Install backend dependencies
```
cd backend
npm install
```
4. Install frontend dependencies
```
cd frontend
npm install
```
5. Install express
```
npm install express
```
6. Install postgresql database
```
npm install pg

```
7. Create a .env file in the root folder and add:
PORT=5000<br>
MONGO_URI=your_mongodb_connection_string<br>

8. Usage
Run Backend:
```
npm start
```
9. Run Frontend:
```
cd Frontend
cd frontend
npm start
``` 
10. Testing
Run tests using:
```
npm test
```
